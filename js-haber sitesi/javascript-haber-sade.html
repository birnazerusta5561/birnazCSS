JavaScript 10 Günde Doğdu

JavaScript, 1995 yılında Brendan Eich tarafından Netscape tarayıcısı için kısa sürede geliştirildi. Bugün tarayıcıların neredeyse tamamında çalışan JavaScript, web sayfalarına hareket ve etkileşim katan dildir.

Java ile adı benzese de iki ayrı dildir. Sık yapılan hata budur.

JavaScript Ne İşe Yarar?

  • Butona tıklayınca bir şey yapar
  • Sayfadaki yazıyı değiştirir
  • Hesaplama yapar
  • Oyun ve animasyon üretir
