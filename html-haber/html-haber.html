HTML Hâlâ Web'in Temeli

HTML, HyperText Markup Language sözcüklerinin kısaltmasıdır. Bir web sayfasının iskeletini oluşturur: başlıklar, paragraflar, resimler ve bağlantılar HTML etiketleriyle yazılır. Yıllar geçse de her web sitesi hâlâ HTML ile başlar.

Uzmanlara göre HTML öğrenmeden CSS ve JavaScript öğrenmek mümkün değil. Önce iskelet, sonra boya ve hareket gelir.

En Çok Kullanılan 5 Etiket

  • div: sayfayı bölümlere ayırır
  • p: paragraf oluşturur
  • a: bağlantı verir
  • img: resim ekler
  • h1-h6: başlık yazar

HTML Öğrenme Sırası

  1. Sayfa iskeleti (html, head, body)
  2. Başlıklar ve paragraflar
  3. Resim ve bağlantılar
  4. Listeler
